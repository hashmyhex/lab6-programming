# Лабораторная работа № 6. Списки и кортежи

Обработка коллекций данных, Python и C++.

## Файлы

- task1.py: случайный список, сумма, среднее, минимум, максимум, сортировка, удаление дубликатов
- task2.py: поиск дубликатов в списке
- task3.py: транспонирование матрицы
- task4.py: кортежи, список студентов
- task5.py: объединение, пересечение и разность списков
- examples.py: примеры со списками, срезами и кортежами
- examples.cpp: примеры с array, vector и tuple
- group7.py и group7.cpp: очередь на списке (enqueue, dequeue)
- merge_sort.py: сортировка слиянием
- matrix_ops.py: сложение, вычитание и умножение матриц

## Запуск

    python task1.py
    g++ -std=c++17 -o group7 group7.cpp
    ./group7
